# Фінанси 6.0

Мобільний PWA-застосунок для щоденного обліку фінансів.

## Нове у версії 6.0

- сучасний інтерфейс у стилі iPhone;
- нижня навігація;
- швидкі кнопки «Дохід» і «Витрата»;
- приховування балансу;
- компанії, рахунки та категорії;
- редагування й видалення операцій;
- пошук і фільтри;
- резервна копія та CSV;
- PIN-код;
- автоматичне перенесення даних із попередніх версій.
