# Фінанси

Персональний PWA-застосунок для обліку доходів і витрат на iPhone.

## Можливості

- доходи, витрати та перекази;
- кілька компаній і особисті фінанси;
- редагування та видалення операцій;
- фільтри;
- PIN-код;
- експорт CSV;
- резервна копія та відновлення;
- встановлення на головний екран iPhone;
- робота офлайн після першого відкриття.

## Публікація через GitHub Pages

1. Завантажте всі файли цього архіву в корінь репозиторію `finances`.
2. Відкрийте **Settings → Pages**.
3. У розділі **Build and deployment → Source** виберіть **GitHub Actions**.
4. Відкрийте вкладку **Actions** і дочекайтеся зеленого статусу.
5. Адреса матиме вигляд:
   `https://ВАШ-ЛОГІН.github.io/finances/`

## Встановлення на iPhone

1. Відкрийте адресу в Safari.
2. Натисніть **Поділитися**.
3. Оберіть **На екран «Додому»**.
4. Увімкніть **Відкрити як вебзастосунок**.
5. Натисніть **Додати**.

## Важливо про дані

Записи зберігаються локально на конкретному пристрої. Інші користувачі, які відкриють сайт, не побачать ваші дані. Регулярно використовуйте кнопку **Резервна копія**.
